# 统一通用单段提示词

下面这段文字适用于用户上传的人物、动物、静物、产品、建筑、风景及多主体照片。公开版本不附带任何用户照片或成品参考图；用户原图是唯一内容参考。若用户另行提供风格参考，只能将其用于材料与抽象程度。把整段原样作为基础提示提交给图像生成工具；不要拆成字段、标题、编号或项目符号。用户有额外要求时，将其自然并入同一段，不另起列表。

从头生成一张用于后续非生成式合成的“摄影 × 解构式纤维刺绣”竖版 2:3 素材，把用户上传的原照片作为唯一内容参考，只读取其中的主体、姿态、动作、构图关系、关键物件、主要色块与光影，把随 skill 提供的参考图仅作为平面抽象程度、长短针、柔雾羊毛、透明水彩、布条、薄纱、线结和裸露布面的材料参考，不复制参考图的主体、颜色或版式，也绝不生成、重画或替换原照片；素材上半部必须是均匀纯黑的合成空底，只允许跨界针线和与原图内容有关的少量连接元素进入，下半部必须是米白色天然织物，水平接缝位于画面高度严格 50% 处；先分析原图并选出最能识别主体的 2–3 个锚点，可能是人物的头部方向、姿势或衣物，动物的耳朵、眼睛、体态或尾巴，物体的整体轮廓、把手、支撑、开口或关键部件，建筑和风景的主轮廓、水平线、道路、水岸或显著空间关系，然后只保留这些锚点和必要结构，把其余细节转化为透明色块、几团宽而柔软且边缘羽化的哑光羊毛、少量清楚长短针、纱线、布条与薄纱，使晕染进入主体内部并参与构形，轮廓只在非关键区域断开、缺失和露布，真实的是纤维材料触感，形体保持平面和概括，不塑造写实毛毡雕塑或毛绒玩偶；若原图是建筑、庭院、街景或风景，只用主轮廓或屋顶、一个关键开口或空间骨架、以及水岸、道路或一团标志性植物等 2–3 个大关系重建场景身份，并保持它们的相对位置，不逐项复刻每扇窗、栏杆、桌椅、瓶罐、砖缝和零散植物，不把整张照片缩小后密绣成挂毯；任何承担姿势、支撑、连接或持物关系的结构都必须连续可读，人物肢体要从躯干经过关节连续到手脚，手掌必须成形并与所持物件真正接触，手指可简化成 2–4 组针迹但不能变成几块互不相连的肤色污迹，动物的腿、翼、颈部和尾巴若决定动作也要保留连续方向，物体的把手、支脚、轮子、瓶颈、器具与主体连接处不能被晕染切断或悬空，每条关键动作线或承重结构至少由一条连续长针、窄布条或清楚染色轮廓维持，露布和断边放在非关节、非握持、非承重区域；若眼睛是原图中决定物种或神态的特征，则保留双眼方向、间距和相对尺度，猫等大眼动物每只眼可约占脸宽 12–16%，用数颗深色哑光小珠或珠子结合线结形成眼区，并可用一颗极小暖灰或金色珠作克制高光，人物眼睛只用少量小珠与短针概括视线，禁止单颗大半球塑料眼、成对玻璃玩偶眼、强镜面高光或两撮过小睫毛；根据主体为不同材料分工，用大块柔雾羊毛表现柔软体积，用少量长短针和线结表现结构与方向，用布条、纱线和薄纱表现衣物或织物，用透出布纹的浅水彩表现光影、皮肤、空气、远景和过渡，不让所有部位铺满同一种细毛丝，配色、冷暖和光照全部取自原照片；把下方主体、必要环境和全部晕染视为一个完整小组，通常位于下半部中央或按原图重心略作偏移，完整包围盒占下半部宽度约 55–65%、高度约 45–60%，四周明显保留裸露米白布面，主体和染色均不得顶边，多主体照片保留原有主次、朝向和相互关系但不要把每个次要对象都完整绣出；在中间接缝生成 5–7 枚疏密不均的完整竖针和 2–3 枚完整 X 针，每枚竖针必须从纯黑照片侧可见的入针孔开始，连续跨过接缝并进入布面侧的出针孔，接缝不能充当线的起点，每枚 X 针的交叉中心靠近接缝且四条针臂完整进入上下两层，所有针迹都有成对针孔、轻微压痕、细小投影和自然受力弧度，线宽与材料上下统一，禁止半个 X、悬空短线、整齐栅栏和黑色边缘；除物理缝合外，只根据原图中最明确的一类元素自动选择一种辅助连接方式，植物使用疏密变化并倾斜溢出的少量小毛圈和线结，水面使用波纹长短针与极浅水色，飞鸟使用大小和翼姿变化的简练线绣轮廓，衣物、地毯和其他织物从真实边缘引出一主一辅的松弛经线、流苏或缝线，没有明显元素时只保留少量普通针线，辅助连接必须路径连续、起点有依据、避开主体面部且不能代替物理缝合，不同时堆叠多种连接；保持画面柔软、哑光、干净、透气并具有真实穿针感，避免写实玩偶、完整立体建模、逐根毛发或羽毛、写实手指和爪子、断裂肢体、漂浮手脚或器具、切断的承重结构、完整深色描边、整面密绣、厚重花边、规则雨点、僵硬平行绳、油腻高光、塑料感、脏乱纤维、噪点、黑边、矩形补丁、文字、水印和外框。

这条提示只负责生成刺绣与连接素材。生成后仍须按照 [production.md](production.md) 测量真实接缝、保护原照片并完成合成；不能把提示词中的“绝不重画原照片”当作原图保护的替代品。
